# DSpark Benchmark Results

在 **8× NVIDIA A800-SXM4-80GB（SM80）/ TP8 / SGLang 0.5.16** 上，对三个 DSpark 参数组合执行完整对比测试。

## 因子设计

三个配置构成一个受控变量矩阵，可分离出两个参数各自的独立影响：

| | `chunked-prefill 16384` | `chunked-prefill 32768` |
|---|---|---|
| **`mem-fraction 0.85`** | 配置 A | **配置 C（推荐）** |
| **`mem-fraction 0.90`** | — | 配置 B |

- **C vs A**（固定 mem=0.85）→ `chunked-prefill-size` 的纯效应
- **C vs B**（固定 chunk=32768）→ `mem-fraction-static` 的纯效应

## 核心结论

**128K 长上下文的性能回退源自 `mem-fraction-static=0.90`，而非 32K chunk。**

- 固定 chunk=32768，仅将 mem 由 `0.90` 降到 `0.85`，128K 三档并发平均回升 **+11.55%**（+14.21% / +11.21% / +9.22%）。
- 固定 mem=0.85，将 chunk 由 `16384` 提到 `32768`，128K 档仅变化 **+1.69%**（+1.67% / +2.75% / +0.64%）。
- 机理：`mem-fraction 0.90` 压缩了可用 KV cache 余量，128K 档 Accept Rate 由 **0.80 跌至 0.69**，投机解码收益被削弱，TPOT 同步劣化（4.172 → 4.740 ms）。

因此上一轮"32K chunk 导致 128K 掉速"的推断是**错误归因** —— 真正的元凶是 `mem-fraction`。

## 需要注意的数据点

诚实标注以下异常，不做隐藏：

- **1K/C1 配置 C 的 +24.81%**：该组两次重复波动仅 **1.04%**（208.32 / 210.50），且 Accept Rate 同步由 0.40 升至 0.56、Accept Len 由 3.0 升至 3.78 —— 指标内部自洽，判定为**真实增益**而非噪声。
- **B 的峰值 1528.32（1K/C16）**：该组波动 **19.73%**，是单点噪声，不能作为 B 的稳定能力。
- **64K/C1 与 64K/C8 配置 A 领先**：C 在此两组分别落后 5.15% / 4.18%，是 C 唯一的明显劣势区间。
- **高波动组统计**：A 6 组、B 6 组、C 3 组（阈值 >5%）。C 的重复稳定性最好。

## 选型建议

- **通用推荐：配置 C**（mem 0.85 + chunk 32768）—— 全场景均衡最优，长上下文不掉速，重复稳定性最好。
- **若流量集中在 64K 单流/低并发**：配置 A 在该区间仍有 4–5% 优势。
- **不推荐配置 B**：其唯一亮点（1K/C16 峰值）是高波动单点，代价是 128K 全面回退与多占约 2 GiB 显存。

## 指标口径

- **Gen Throughput**：本组所有成功请求的 completion tokens / 组墙钟时间。
- **Accept Rate / Accept Len**：只解析该组对应的 SGLang `Decode batch` 日志字节区间。
- **TTFT**：请求发出到首个非空流式内容事件。
- **TPOT / ITL**：首 token 后按 completion token 数归一化。
- **GPU Utilization / Memory / Power**：`nvidia-smi` 每 0.5 秒采样，GPU0–7 分别记录。
- **Peak VRAM**：本组 GPU0–7 的最高采样显存。
- **波动**：同一 Context / Concurrency 下两次完整重复的 Gen Throughput 相对差异。超过 5% 的组应视为需要额外重复验证，而不是隐藏或删除。

## 可复现性说明

测试脚本会校验服务进程中的 `mem-fraction-static`、`chunked-prefill-size` 和 `max-running-requests` 实参，
且未发现 AR/AL 时会直接停止，避免生成指标缺失的报告。
输入 prompt 经本地 tokenizer 构造为精确的 1K/4K/16K/64K/128K token 档位，服务端 `usage.prompt_tokens` 同时记录到原始 JSON。
三轮测试均在同一台机器、同一模型权重、同一 SGLang 版本下连续执行。
